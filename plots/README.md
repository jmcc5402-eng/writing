## Arc 1 destination ideas (Books 3–10)

Arc 1 is "first cases — simple mysteries, basic skills." Good early cities pair a
strong real-world culture/geography with a kid-friendly, non-scary mystery:

- A canal city (Venice / Amsterdam) — something lost in the waterways
- A safari town (Kenya / Tanzania) — animals being moved or released
- A ski town (Swiss Alps / Colorado) — a weather-driven mystery
- A tech city (Singapore / Seoul) — a light hacking / gadget case
- A desert/ruins city (Cairo / Petra) — a "map" mystery like Book 1's cousin
- A rainforest city (Costa Rica) — an environmental/water mystery

_Pull the core mystery for each from the plot-type menu in the series bible, and
make sure each book teaches a new skill from the skills ladder._
