# Set One First — does the mega-set tax Books 1–4?

**Status: ALL PROPOSED.** Main-thread structural read, 2026-08-11
(no agent run, no variance card). Prompted by the author's direction:
*we are not sacrificing good initial books to a perfect sixteen-book
mega-set; the priority is that Books 1–4 are great.* This
operationalizes the quartet-first author note already locked in
STANDARDS (2026-08-08) — the note said it; the docs and the queue
don't yet obey it.

**Method:** every Set-1-facing obligation in ADULT-CAST-IDEAS.md, the
plot sweep, and the alignment audit was asked one question — *does
Book N pay for this locally, or is it freight for a book that may
never exist?*

**Verdict up front:** the page is mostly healthy; the process is not.
The sweep's double-duty discipline means nearly every series plant in
Set 1 already pays local rent — the covenant wins 1.4's vote, the
letter points to the deed, the receipts and the 2009 photo beat Boyd.
The real mega-set taxes are in the **queue**: finale-first ordering,
a four-town prerequisite, and Set 2–4 gates queued as if they block
Set 1. One on-page item needs fixing (F4). Nothing here asks to redo
the sweep's Set 1 spine — protect it.

---

## F1 — Finale-first ordering inverts the locked priority

The alignment audit's cluster 1 says the 4.4 finale mechanism
"constrains plants in every earlier book; nothing else can lock
first." Under quartet-first, that is backwards: it makes the hardest,
least-certain artifact — a hearing twelve-plus books away — the gate
for the four books that must be great now.

**Proposal: replace the finale mechanism with a severability
interface.** Set 1 owes the future exactly three artifacts, all of
which it already carries for its own local reasons:

1. **The letters exist** and are unexplained (1.2's wall find,
   already load-bearing locally — it points to the deed).
2. **The deed carries one odd, unremarked line** (the sunset clause —
   one sentence of texture in 1.4).
3. **The House survives as a working program** (Set 1's own victory
   condition).

That is the entire contract. The codicil chain, the hearing's winning
logic, and what each exhibit proves get designed at Set 4 bible time,
*from what Set 1 actually shipped*. Plans built on accepted books
beat books built on unbuilt plans — this is the Stagger rule's own
logic (N+2 holds premise only; staleness re-gates). Related: 4.4
currently holds midpoint-level detail (PONR at 50%, hearing at ~90%)
— that is N+15 material held far above its rung. Carry 4.4 as
premise; stop refining it until Set 4.

**Honest cost:** if Set 1 ships before the finale is designed, Set 4
may someday wish Set 1 had planted differently. The three-artifact
interface is the insurance, and it is cheap precisely because all
three artifacts do local work anyway. A letter can mean anything
later; a fully specified codicil chain can only mean one thing, and
must be right today about a book years away.

## F2 — Quartet severability should be a standard, not a vibe

Proposed as STANDARDS item 22 (in this PR): each quartet lands
complete for a reader who stops there — set antagonist beaten on the
page, all four HEAs delivered, and every dangling series thread
reading as **texture** (an unexplained letter, one odd line in a
deed, two strangers arguing at a party), never as a **promise** (no
cliffhanger, no OWED debt a set-only reader can feel as unpaid).
S## threads still carry OWED markers internally; the standard governs
what the *reader* feels, not what the ledger tracks.

## F3 — Plants pay local rent (make the sweep's discipline a rule)

Proposed as STANDARDS item 23: no Set 1 scene exists only to serve a
later set; every series plant must also advance its own book's A- or
B-story. The existing seeds pass this test — the rule exists so
future outlining keeps passing it. Corollary, same item: **Set 1 gets
first pick.** The sixteen-book contracts (the no-repeat trope grid,
S## payoff slots, reserved finale moves) are warnings for Set 1, not
walls — if a Set 1 outline wants a move reserved for book 11, Set 1
takes it and the future adapts.

## F4 — The one on-page freight: the S03 cameo couple

Coordinator × counsel are Set 1's only unpaid passengers: unnamed,
slot-contradictory (audit 22), and their 1.4 convocation scene spends
finale pages on two strangers whose story starts twelve books later.
**Fix inside Set 1's own logic, not by cutting:** give both local
jobs in 1.4 — she runs the convocation the vote campaign culminates
at; he is the trust's junior counsel sent up *because the covenant
fight exposed the trust* — so their argument is about Book 1.4's
plot. Name them now. If Set 4 never happens, they were still two
sharp minor characters. That is severability in action.

## F5 — Build one town, not four

The audit demands a town census per set as a bible prerequisite.
Scoped to quartet-first: **full census for the Ashford town only** —
name, map, non-campus economy, and the civic machinery that holds
1.4's vote (the council venue, audit blocker 10). Towns 2–4 hold at
one paragraph each until their set enters outline. Same re-scope for
the timeline: Set 1's academic year plus birth years for the Set 1
cast and the two or three carry-through adults — not sixteen books of
age math.

## F6 — SUPERCONCEPTS.md does not exist, and it gates everything

Hard rule 8: every book keeps a SUPERCONCEPTS.md, and editorial
agents judge chapters against it. The campus series has none — the
mega-themes live in BRAINSTORM §5 (pre-pivot) and one candidate in
STANDARDS 21. For Books 1–4 to be great, the file every editor
judges them by must exist first, and it must be written about what
makes **one book** great (cozy is earned; load-bearing obstacles;
the town is the character; home is a person) — not about mega-arc
payoff. No superconcept may require a reader to care about Set 4.

## F7 — What is already healthy (protect in revision)

- The sweep's Set 1 spine: midpoints, earned resolutions, the
  false-alarm and culprit-bench placements. Do not reopen.
- S01/S05/S11 in Set 1: all double-duty as designed.
- The matchmaker touches: one deniable beat per book, already
  specified for Set 1; identity can wait until Set 2 outlining.
- The container at local scale: in Set 1 the trust is a deed and a
  house, not a mythology. Keep it that size.
- The season/register map: every Set 1 book is a native fit.
