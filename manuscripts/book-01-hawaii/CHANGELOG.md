# Book 1 — Changelog

Tracks edits made to the manuscript after import, so the author can see exactly
what changed from the original Google Doc.

## Import (from "Hawaii – Full text v6.docx")
- Imported the full 12-chapter text verbatim.
- Removed export artifacts: Markdown escape characters (`\!`, `\-`) left over
  from the Google Docs → Markdown conversion. **No wording changed.**
- Normalized all chapter headings to a consistent `## Chapter N: Title` format
  (the source mixed `# Chapter`, bare `Chapter`, etc.).
- Added a title block and a source note at the top of the file.

## Continuity fix
- **Villain name:** corrected two Chapter 7 references from **"Dr. Chen"** to
  **"Dr. Lee,"** matching the villain's name everywhere else in the book
  (Dr. Marcus Lee). *Left "Coach Chen" untouched — that is Amanda's Seattle
  soccer coach, a separate, intentional character.*

## Polish pass 1 (copy edits — no story changes)
- Normalized all quotation marks and apostrophes to straight quotes for a
  consistent working draft (the export mixed curly and straight). A publishing
  tool can "educate" these back to curly at layout time.
- Fixed typos/grammar:
  - "Amanda sat a desk" → "sat at a desk"
  - "the twin's parents" → "the twins' parents"; "the Kalani's living room" →
    "the Kalanis' living room"; "the evenings events" → "the evening's events"
  - Added a missing period to Uncle Jacob's line ("...chat with them.")
  - Removed stray spaces before three closing quotation marks (Chapter 10)
  - Hyphenation: "side eyed" → "side-eyed"; "fenced in yard" → "fenced-in yard"
  - Standardized "WIFI"/"WiFi" → "Wi-Fi"
