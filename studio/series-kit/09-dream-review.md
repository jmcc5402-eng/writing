# Template — The Dream Review (working backwards from the rave)

_Proven by: all three books' `notes/dream-review.md`. Method: write
the review the finished book earns, mark the skin-tingle sentences,
then reverse-engineer what must exist on the page for each one to be
true. One production dream review's single recommendation became a
locked canon decision within hours — this artifact moves plots._
