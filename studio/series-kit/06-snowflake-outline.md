**Kit notes.**
- For a rewrite of an existing draft, precede this with the analyst
  layer: 2–3 parallel specialist analyses (plot / character /
  continuity — or argument / voice / lexicon) with numbered findings
  (P1…, K1…, E1…), then a synthesis snowflake that issues numbered
  RULINGS and a binding requirements list. Drafts then cite rulings
  by ID — that traceability is what made revision auditable.
- Density targets (words per chapter, cadence) go in the directives;
  drafters report against them.
