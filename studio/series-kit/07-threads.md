**Kit notes.**
- `OWED:` is the load-bearing marker — it is foreshadowing discipline
  made greppable. The knowledge-thread type tracks who-knows-what
  (superior position lives there).
- NON-FICTION slot names: CLAIMS / USES / CALLS BACK / PLANTS /
  <product-feature slot> / HANDS FWD / FLAGS. Repetition inverts: in
  non-fiction, recurring devices are the asset — index deliberate
  repetition, flag only the unintentional.
