# Banned Moves (recency ledger)

Devices an agent leaned on recently, banned for its next run. This is the
reactive half of the variance system: the decks add planned variety; this
prevents repetition the critics have already caught.

Maintenance: after a drafting or critique run, append what the review
flagged; drop an entry after two clean runs without it. Include the current
list in the agent's invocation as "banned moves this run."
